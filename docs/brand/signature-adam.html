Signature e-mail — Adam Fernandez

Cliquer sur « Copier la signature », puis coller directement dans le client mail.

Aperçu

  1. Gmail — Paramètres → Général → Signature → coller
  2. Outlook — Fichier → Options → Courrier → Signatures → coller
  3. Apple Mail — Réglages → Signatures → décocher « Toujours utiliser la police par défaut », puis coller
